Overview

Tape CSV/TSV uuid tables for quick inspection and cleanup. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/tapeuuid.git
cd tapeuuid
node src/cli.js --help
node --test
