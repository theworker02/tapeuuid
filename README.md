# tapeuuid

Tape CSV/TSV uuid tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/tapeuuid/

## Install / run

```bash
git clone https://github.com/theworker02/tapeuuid.git
cd tapeuuid
node src/cli.js
node --test
```
